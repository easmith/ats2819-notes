# Документация

Записи по обратной разработке платформы Actions ATS2819 / US281B, полученные на наушниках с
костной проводимостью AGPTEK S22. [English version](../en/00-index.md).

| Документ | О чём |
|---|---|
| [01-device.md](01-device.md) | Устройство: идентификаторы, управление, сервисный режим ADFU и как понять, тот же ли у вас чип |
| [02-flash-format.md](02-flash-format.md) | Чип: как данные физически лежат во флеше, регистры SPI0, рандомайзер и зерно, исполнение из флеша |
| [03-firmware-layout.md](03-firmware-layout.md) | Прошивка: загрузочные записи, образ LFI, 47 файлов, `tts_rc.lib`, `config.bin` |

Если собираетесь что-то писать в устройство — начните с [SAFETY.ru.md](../../SAFETY.ru.md).

Черновые записи с адресами и дизассемблером — в `notes/`; эта документация —
связное изложение того, что в них.
