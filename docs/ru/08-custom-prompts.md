# Голосовые подсказки на своём языке

[English version](../en/08-custom-prompts.md).

В прошивке 31 китайская подсказка и ни одной английской, а переключателя второго языка нет, так что
единственный путь — заменить таблицу подсказок. Эта таблица — один файл внутри образа прошивки,
поэтому такая замена и есть самое щадящее изменение, какое можно внести в эти наушники; ради неё
весь репозиторий и собран.

## 31 подсказка

Идентификаторы — по перечислению `common_tts_id.h` из SDK. Это те, которые реально есть в заводской
прошивке; пропуски (4–7, 10, 13, 16, 21, 34, 36) — подсказки, которые это изделие не использует.

## Сборка таблицы

В `tools/make_tts.py` тексты лежат в словаре `PROMPTS` — id → (язык 0, язык 1), — и скрипт собирает
таблицу в заводском формате:

```bash
python3 tools/make_tts.py build/tts
#   -> build/tts/tts_rc.lib и build/tts/clips/*.mp3
```

Каждая фраза синтезируется командой `say` из macOS, конвертируется `ffmpeg` и кодируется `lame` в
MP3 16 кГц, 16 кбит/с, моно, постоянный битрейт — именно это ждёт декодер прошивки. Пересборка
опубликованной таблицы таким образом воспроизводит её **побайтно**, то есть выложенный файл — ровно
то, что делает скрипт.

Чтобы поменять язык или формулировки, правьте `PROMPTS` (и `VOICES` — голоса) и пересоберите. На
машине без `say` подставьте любой синтез, умеющий отдать моно 16 кГц WAV, и оставьте вызов `lame`.

## Ограничение по размеру — главное ограничение

Между концом образа прошивки и областью VRAM по логическому `0xF0000` свободно **56 768 байт**.
Заводская таблица — 39 872 байта, значит замена может быть примерно до 96 КБ целиком.

Русско-английская таблица здесь — **87 280 байт**, на 47 408 больше заводской, запас около 9 КБ.
Двуязычный набор в естественных формулировках вышел около 112 КБ и не влез — поэтому фразы такие
короткие («Жду связи», а не «Ожидание подключения»). Если нужны длинные формулировки, выкиньте
ненужные подсказки: одни цифры — это десять из тридцати одной.

## Как положить это в устройство

```bash
python3 tools/build_fw.py                     # build/fw/afi_plain.bin и build/fw/UPGRADE.HEX
echo WRITE | sudo .venv/bin/python tools/adfu_flash.py ours --write --verify 0x5000
```

`build_fw.py` берёт заводской образ, подменяет `TTS_RC.LIB` новой таблицей, сдвигает файлы после
неё, исправляет все контрольные суммы и откажется собрать образ, у которого LFI дотянется до VRAM.
Дальше полностью применим [06-flashing.md](06-flashing.md) — включая приёмочное чтение, в котором
весь смысл.

Чтобы прошить подсказки, опубликованные здесь, ничего не собирая, сразу переходите к записи: `ours`
подхватывает `firmware/prompts-ru-en/afi_plain.bin`.

## Второй язык собран, но недостижим

В `tts_rc.lib` два слота на подсказку, а в заводском `case/fwpkg/tts_flist.txt` из SDK — список в
две колонки, китайская и английская, причём все английские слоты NULL. Это и есть заводской
механизм второго языка, и это изделие вышло с пустой второй колонкой.

Собранная здесь таблица заполняет **обе** колонки: русский в слоте 0, английский в слоте 1.
Устройство играет слот 0. Ничего, что выбирало бы слот 1, в прошивке найти не удалось — ни
комбинации кнопок, ни настройки, — а поскольку в заводской прошивке английских записей не было
вовсе, переключатель может быть просто недостижим без правки кода прошивки. Английский звук лежит
готовым, если кто-нибудь разберётся, как переключать язык. Если разберётесь — заводите issue.
